# elevation-profiles/

Drop elevation-profile screenshots here — one per hike (optional; leave the `elevation_profile` column blank on the form if you don't have one for a given hike).

**Naming:** same idea as the routes folder — whatever you type into the `elevation_profile` column just needs to match the filename exactly.

```
##-peak-name-YYYY-MM.png
```

Example: `07-gray-peak-2024-09.png`

**How to get the file:** in the AllTrails app, the elevation chart on the completed-hike page — screenshot it and save here.
