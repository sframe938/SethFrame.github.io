# routes/

Drop AllTrails route exports (`.kml` files) here — one per hike.

**Naming:** anything is fine as long as it matches exactly what you type into the `route_file` column on the form/spreadsheet for that hike. The convention used so far is:

```
##-peak-name-YYYY-MM.kml
```

Example: `07-gray-peak-2024-09.kml` (peak #7, Gray Peak, climbed September 2024).

The `##` is the peak's number from the skyline — not required, just makes the folder easier to scan later.

**How to get the file:** in the AllTrails app, open the completed hike → Share/Export → Export as KML. Save it here with the matching filename.
