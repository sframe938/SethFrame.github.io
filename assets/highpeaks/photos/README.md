# photos/

Drop a summit (or trail) photo here for each hike — optional; leave the `photo` column blank on the form if you don't have one yet.

**Naming:** whatever you type into the `photo` column just needs to match the filename exactly.

```
##-peak-name-YYYY-MM.jpg
```

Example: `07-gray-peak-2024-09.jpg`

Any normal photo format works (jpg, png, etc.) — just make sure the file extension in the filename matches what you actually saved.
